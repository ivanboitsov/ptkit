# ptkit

Неофициальная Python-библиотека для API продуктов Positive Technologies.
Сейчас: MaxPatrol VM, только чтение. Подробно: docs/design.md.

## Принципы (не нарушать без нового ADR в docs/adr/)
- Единственная точка входа: `ptkit.vm.Client`. Глобального конфига нет.
- Только чтение. Никаких методов, меняющих данные в MaxPatrol.
- Зависимости: только `requests`. Новая зависимость = новый ADR.
- Сырой PDQL всегда доступен; построитель не обязан покрывать весь язык.
- Всё, что зависит от версии MaxPatrol, только в `ptkit/vm/_compat.py`.
- У объектов ответа всегда есть `.raw` с исходным JSON.
- Токен никогда не попадает в логи, исключения и repr.

## Команды
- Тесты без сервера: `pytest tests/unit`
- Линтер и типы: `ruff check . && mypy ptkit`
- Диаграмма классов: см. docs/architecture.md

## Правила работы
- Работа только в отдельной ветке, не в main.
- Коммиты в формате Conventional Commits (см. CONTRIBUTING.md).
- Изменил публичные классы или связи между ними: обнови схему в docs/architecture.md.
- Перед коммитом прогоняй unit-тесты.
- Не выдумывай поля и эндпоинты MaxPatrol: если не знаешь, спроси или оставь TODO.
